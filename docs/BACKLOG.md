# 남은 개발 목록

첫 버전의 범위는 소유자 전용 관리 앱이다. 작품 설정, 제작 도구 채택, 예산과 일정은 모두 미정이다.

1. 호스팅 선택 후 HTTPS, 관리형 인증, 영구 볼륨, 운영 백업 정책 및 비공개 배포 검증. 현재 환경에는 Sites 개발·배포 도구가 없고 게시도 요청받지 않았다.
2. Notion 읽기 접근 또는 사용자가 제공하는 내보내기 자료를 확보하고 실제 하위 구조/양식/관계와 대조. 이관 충돌의 수동 병합 UI, ZIP 일괄 이관, 타입별 원본 관계 매핑.
3. 다중 사용자 초대와 프로젝트별 읽기/편집/승인/관리 역할. 현재는 검증된 소유자만 접근할 수 있고 다른 역할과 가입은 제공하지 않는다.
4. 별도 제작 워크스테이션. 로컬 파일·GPU·렌더링·실행 어댑터·모델 관리는 여기서 구현하지 않는다. `workstation-handoff/`의 v1 계약을 먼저 공유한다.
5. 실시간 동기화·원격 실행은 별도 설계 및 권한 검토 후 진행한다. 현재 파일 교환만 지원하고 연결 상태는 미연결이다.
6. 대용량 미디어 스토리지, 영상 트랜스코딩, 오디오 파형, 세부 예산 통화 환산, 자동 일정 계획은 후속 범위다. 현재 비용은 수동/실제/추정/미상을 구분하는 메타데이터다.
7. 문서 동시 편집과 정교한 텍스트 병합은 후속이다. 현재 revision 기반 충돌 거부로 조용한 덮어쓰기를 방지한다.

유료 API 호출·외부 도구 가입·결제·팀 초대는 수행하지 않았다.
