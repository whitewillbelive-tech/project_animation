## 가져오기 경로

소유자가 Notion에서 내보낸 Markdown 또는 CSV 파일을 앱의 이관 화면에서 선택한다. 자동으로 Notion에 접속하거나 변경하지 않는다. Markdown은 한 파일을 한 문서로, CSV는 행을 개별 기록으로 처리한다. CSV 권장 헤더는 `원본 ID,제목,유형,카테고리,내용,원본 링크,원본 수정 시각`이다. 영어 `id,title,type,category,content,url,modified_at`도 지원한다. 유형은 내부 enum을 사용하고 미지정 값은 문서로 처리하며 경고를 남긴다. 작품 본문과 해석·각색·AI 제안은 별도 문서/분류 필드로 기록한다.

원본 ID가 없으면 내보내기 파일명과 행 번호에서 합성 ID를 만들고 경고한다. 이때 파일명·행 순서가 바뀌면 동일 원본 판별이 제한되므로 가능하면 원본 ID를 제공해야 한다. 원본 수정 시각은 제공한 경우에만 보존하며 추측하지 않는다. 읽은 시각은 파일을 서버가 읽은 UTC 시각이다.

서버가 실제 저장 전 미리보기와 충돌을 계산한다. 같은 프로젝트·원본 ID·내용은 중복 생성하지 않는다. 기존에 가져온 내용과 다른 원본, 사용자가 편집한 기존 기록은 충돌로 표시하고 자동 덮어쓰지 않는다. 충돌 해소·관계 자동 매핑·ZIP 일괄 이관·Notion 실시간 동기화는 후속 작업이다. 민감한 원문은 SQLite에 저장되며 정적 번들 또는 handoff에 넣지 않는다.
