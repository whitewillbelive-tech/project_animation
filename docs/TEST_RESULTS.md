## 현재 인스턴스와 미검증 범위

- 기본 루프백 서버를 실행했고 `/`와 `/api/session`의 HTTP 200 응답을 확인했다. 소유자 계정은 사용자가 터미널에서 생성해야 하며 임의 암호를 만들지 않았다.
- Notion 루트 읽기 요청은 프록시 CONNECT 403으로 실패했다. 내용·관계·원본 변경 시각은 읽지 못했고 실제 이관은 미완료다. 원본 수정·삭제·공유 변경 요청은 수행하지 않았다. 원본의 전후 내용을 대조한 것은 아니다.
- Sites 도구가 없어 비공개 호스팅 배포·외부 접속·HTTPS 프록시 운영·플랫폼 인증 연동은 미검증이다. 로컬 실행을 배포 완료로 보지 않는다.
- 실제 워크스테이션은 없으며 fixture로 계약만 검증했다. 실제 AI 생성/렌더링/GPU/유료 API/도구 설치는 수행하지 않았다.
- 다른 브라우저·스크린리더의 수동 검수, 운영 부하·장기간 복구·관리형 인증·팀별 권한은 미검증/후속이다. 이번 버전은 소유자 전용이다.
