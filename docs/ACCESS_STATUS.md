# 관리 Site 접속·배포 상태 · 2026-11-06 재확인

**사용자 PC에서 접속할 실제 Site 주소는 아직 없다. 비공개 배포는 미완료이며 현재 도구로 진행할 수 없다.**

## 원인과 실행 위치

- 앱은 사용자 PC가 아니라 플랫폼이 제공한 원격 Linux 클라우드 환경의 `/workspace/project_animation`에 있다. 런타임 상태 API는 provider=cloud, running, connected를 보고한다.
- 앞서 안내한 `127.0.0.1:8000`은 이 원격 환경 안의 개발용 루프백 주소다. 사용자가 자신의 PC에서 이 주소를 열면 사용자 PC 자신에 접속하므로 원격 앱에 도달하지 않는다.
- 이번 점검 시작 시 기존 앱 프로세스와 8000 리스너가 없었다. 실제 읽기 요청은 `[Errno 111] Connection refused`, Chromium은 `net::ERR_CONNECTION_REFUSED`였다. 이전 프로세스의 종료 원인을 설명할 로그는 확보되지 않았다. 포트가 외부에 게시되었던 것은 아니다.
- 기존 앱의 정확한 명령 `python3 -m app.server --host 127.0.0.1 --port 8000`으로만 재기동해 정상 기동을 확인했다. 이는 내부 진단이며 사용자 PC의 접속 문제를 해결하거나 Site를 배포한 것이 아니다.

## Sites 등록·배포 확인 한계

이 채팅에서 Sites 등록·배포를 수행한 이력은 없다. 저장소에도 Sites의 배포용 project_id·배포 메타데이터는 발견하지 못했다. 앱 내부 데이터 계약의 `project_id`와 클라우드 환경 식별자는 Sites 프로젝트 ID가 아니다.

현재 제공된 전체 도구 목록과 클라우드 스킬 목록을 다시 확인했지만 Sites 목록/기존 프로젝트 조회/등록/비공개 배포/상태 조회 도구와 지침은 제공되지 않았다. 따라서 다른 경로로 이미 등록된 Site가 존재하는지는 조회할 수 없으며 기존 Sites project_id나 배포 상태도 확인할 수 없다. **막힌 단계는 Sites 프로젝트 조회 및 비공개 배포 API 호출 자체**다. 배포 요청을 보내지 못했으므로 배포 API의 권한 오류 코드 또는 실패 로그가 있다고 주장하지 않는다.

기존 프로젝트 조회와 비공개 배포가 가능한 Sites 도구가 이 작업 환경에 제공되어야 진행할 수 있다. 도구가 제공되면 먼저 기존 프로젝트를 조회하고, 확인된 기존 project_id를 재사용하여 비공개 배포·인증·영구 저장을 검증한다. 임의 API/배포 명령, 공개 터널, 공개 전환, 중복 Site 생성, 방화벽 해제는 수행하지 않았다. 클라우드 환경 게시도 Site 배포의 대체 수단으로 취급하지 않는다.

## 보존과 검증

- 변경 전 기존 소스·문서를 `/workspace/preservation/site-access-20261106T090153Z/site-source.tar.gz`에 보존했다. SQLite 백업 API로 같은 디렉터리에 `animation.sqlite3`를 백업했고 무결성 결과는 `ok`다. `checksums.json`에 파일 해시를 기록했다.
- 현재 DB를 읽기 전용으로 검사한 결과 무결성 `ok`, 소유자/프로젝트/기록/이력/가져오기 모두 0건이다. 기존 값을 삭제하거나 초기화하지 않았고 계정을 임의 생성하지 않았다. 이는 현재 인스턴스 DB에 대한 관찰이며 다른 환경의 데이터 유무를 뜻하지 않는다.
- 재기동 후 원격 환경 내부 Chromium에서 실제 로그인 화면이 열림(HTTP 200), JavaScript 오류 0개. `/api/session`은 HTTP 200, authenticated=false, `/api/state`는 HTTP 401이다. 현재 소유자가 없으므로 이 인스턴스의 로그인 후 저장은 검증할 수 없다.
- 기존 SQLite 재연결 저장 테스트 `test_all_types_save_and_persist_after_reconnect` 1개를 임시 DB에서 다시 실행해 통과했다. 사용자 데이터는 수정하지 않았다. 이 결과는 배포 주소에서의 저장 검증을 뜻하지 않는다.
- 사용자 PC에서 실제 배포 화면 열기·인증·데이터 저장 후 재접속: **미검증 / 비공개 배포 도구 부재로 차단**.

이번 변경은 접속 설명과 이 보고서뿐이며 앱 로직·기록·데이터 계약을 수정하지 않았다. 워크스테이션 개발도 시작하지 않았다.
